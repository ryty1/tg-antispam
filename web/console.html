关键词规则配置

新规则
多个关键字用英文逗号分隔
通用变量 （所有操作都可用，发送时替换成真实值）
{mention}触发者的可点击提及，点一下直接打开对方资料
{name}触发者昵称（名+姓），没有昵称时回退成 @用户名
{username}触发者的 @用户名，没设置时显示「未设置」
{id}触发者的数字用户 ID
{chat_title}当前群组 / 频道的标题
积分与冷却变量 （仅「增加积分 / 减少积分」有值，其它操作会渲染成空）
{points}本次实际生效的积分数（扣分时若余额不足，这里是按余额封顶后的真实值）
{points_delta}带符号的变动量，如 +10 / -5
{points_total}变动后的积分余额，{balance} 是它的同义写法
{cooldown}本规则配置的冷却时长，如 1天，适合写「下次 1天 后再来」
{cooldown_remain_text}剩余冷却时间的中文写法，如 23小时59分；本框（命中成功）里为空，只在下方冷却模板有值
{cooldown_remain}剩余冷却秒数，如 86399；本框里为空，只在下方冷却模板有值
{cooldown_next}下次可触发的北京时间，如 08-13 09:05；本框里为空，只在下方冷却模板有值
{cooldown_reset}自然周期的重置时间点，如 00:00；仅冷却单位为天/周/月/年时有值
命中成功时剩余冷却为 0，所以上面三个 {cooldown_remain*} / {cooldown_next} 会渲染成空串而不是 0秒，避免出现「还需等待 」这种半截话。旧写法 $mention @username $code_id $code_name $delay_delete 仍然兼容。
命中后为发言人增加的积分
冷却期内再次命中该规则会被静默忽略（不回复、不加减分）
天及以上按自然周期计算：到点进入新周期即可再次触发
留空 = 冷却期内静默不回复（不加减分、也不发消息） 0/1000
冷却专用变量 （上面的通用变量与 {points_total} 同样可用）
{cooldown_remain_text}剩余冷却时间的中文写法，如 23小时59分
{cooldown_remain}剩余冷却秒数，如 86399，适合自己拼文案
{cooldown_next}下次可触发的北京时间，如 08-13 09:05
{cooldown}本规则配置的冷却时长，如 1天
{cooldown_reset}自然周期的重置时间点，如 00:00，可写「每天 {cooldown_reset} 重置」
冷却命中时不动积分，所以 {points} 与 {points_delta} 都是 0，{points_total} 仍是当前余额。
